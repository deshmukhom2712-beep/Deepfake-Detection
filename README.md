# Deepfake Detection Using Deep Learning

## About the Project
This project focuses on detecting deepfake images using deep learning and computer vision techniques.

## Technologies Used
- Python
- Jupyter Notebook
- Deep Learning
- Computer Vision

## Project Files
- `Training_file_deepfake.ipynb` — Model training and experimentation
- `app.py` — Application code
- `testing2.py` — Testing script

## Key Objectives
- Explore deepfake image detection.
- Apply deep learning techniques to image classification.
- Build a foundation for a practical detection application.

## Future Improvements
- Add model evaluation metrics.
- Include sample prediction screenshots.
- Improve the user interface and explainability.

## Disclaimer
Predictions may be incorrect. Results depend on the dataset and model performance.
